# AI Study Assistant

An AI-powered Streamlit application that generates quiz questions from uploaded study material images using the Gemini API.

## Features

- Upload up to 3 images of notes
- AI-generated quiz questions
- Difficulty selection:
  - Easy
  - Medium
  - Hard
- Multiple quiz sizes
- Clean Streamlit UI

## Tech Stack

- Python
- Streamlit
- Google Gemini API
